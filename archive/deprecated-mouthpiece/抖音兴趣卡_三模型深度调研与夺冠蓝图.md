## 一、 海报深度拆解与赛道本质洞察

### 1.1 官方海报传递的五大隐性信号
从官方招募海报《你的第一个 AI 产品》的全部细节拆解，这绝不只是一场普通的校园编程练习，而是抖音在 **2026 年“可玩式 AI 内容（Playable AI Content）”战略级抢跑**中的样板间选拔工程：

1. **媒介革命（从 Watch 到 Play）**：
   - 兴趣卡是**直接混排在抖音首页推荐信息流（Feed 流）中的原生可交互 AI 内容卡**。无需跳出抖音、无需加载第三方小程序，刷到即玩，且直接进入推荐算法赛马池。
2. **开发范式（AI 工坊 × Vibe Coding）**：
   - 依托创作者中心内置的「AI 工坊」，底层打通**豆包大模型推理接口 + 动态前端 UI 容器 + 抖音云存储服务**。既支持零基础自然语言搭建，又允许进阶者深入底层代码与 JSON 配置做精细化控制。
3. **跨平台错位竞争格局（Carbon 横向调研）**：
   | 维度 | 抖音「AI工坊 × 兴趣卡」 | 小红书「Builder / RED Skill」 | B站「Toy」 |
   | :--- | :--- | :--- | :--- |
   | **分发入口** | **首页公域推荐流直接刷出（算法找人）** | 种草图文/视频笔记下方挂载（搜索/种草延伸） | UP主视频下方/评论区独立体验（社区造梗） |

## 二、 Neon × Carbon × GPT 三轮交叉辩论全纪实

为彻底消除单一视角盲区，三方进行了三轮针锋相对的红队挑刺与收敛迭代：

### 🔄 第一轮（独立发散）→ 第二轮（红队撕扯与淘汰）核心交锋

#### 交锋 1：娱乐流心流错配 vs 拟人合规红线
- **GPT 第一轮立场**：查证《人工智能拟人化互动服务管理暂行办法》（2026 年 7 月 15 日施行）及 AI 工坊服务协议后，预警“持续拟人化情感依赖”与“专业建议”合规风险，提议转向纯确定性工具（如《这句怎么回》《图表找破绽》《无刀纸盒改造》《同景三镜》）。
- **Neon & Carbon 联合反击**：在夜间 11 点半用户躺床单手刷抖音的 **Lean-back 娱乐流**里，刷到《图表找破绽》会在 0.8 秒内被当成“上课作业/枯燥落地页”划走！而官方标杆《青松蛙》《Gyminimal》本身就是动物 IP。
- **三方合议定论**：法规打击的是**“仿真人恋爱成瘾/擦边陪聊/医疗心理诊断”**，而非卡通功能型动物 NPC。最优解是 **「非人化卡通动物 IP 演出壳 × 确定性高频问题解决核」**，并严格执行**“随案出现、2 回合落锤主动送客、明示 AI 生成标识、零排他情感诱导”**四条合规护栏。GPT 当场认账，主动淘汰《图表找破绽》《纸盒改造局》《同景三镜》。

#### 交锋 2：抖音宿主容器“全向手势地雷阵”（三轮接力排雷！）
- **第一轮盲区**：Neon 在《嘴替救援队》中设计了“水平拖动双轴滑块（0% 卑微 → 100% 创飞全场）”和左右滑卡。
- **第二轮 Carbon 排雷**：补全抖音推荐流手势占用图——不仅**上下滑 = 切视频**，而且**左滑 = 进作者个人主页**、**右滑 = 切顶部同城/关注频道**、**空白双击 = 点赞红心**！水平滑块在真机极易触发切页，且拖动会引发高频 LLM 请求风暴。Neon 遂在第二轮改为“单指长按 0.6s 蓄力敲槌”。
- **第三轮 GPT + Carbon 终极排雷**：**在抖音推荐流中，“长按屏幕”同样被宿主最高优先级接管（直接弹出“倍速播放 / 不感兴趣 / 举报 / 清屏”原生半屏菜单）！**
- **第三轮 Neon 终极拍板**：彻底废除一切横滑、拖拽与长按！全卡收敛为 **100% 显式单指点按（Pure Tap）**，并用**“程序化伪蓄力（单指轻点 → 140ms 木槌自动抬升 → 60ms Hit-Stop 顿帧 → 4px 衰减震屏 + 红章飞入 + 碎纸粒子）”**实现满级游戏打击感！

#### 交锋 3：「150ms 瞬时响应」与「Delete-LLM 测试」的工程悖论
- **悖论起因**：GPT 第一轮提议点击后先直接展示预审静态模板答案，异步加载 AI 增强（超时则直接用模板）。Carbon 与 Neon 质询：**如果静态模板就能直接给答案，Demo Day 评委一句“把大模型删掉换成静态表有什么区别（The Delete-LLM Test）”就会让项目当场出局！**
- **三方共创解法（分层混合状态机）**：
  - **Layer 0（端侧 `<50ms~150ms` 立案反馈，不剧透答案）**：点击瞬间播放角色拍案动画 + 端侧 JS 规则计算确定性锚点（如将商品金额按整数分换算为 `= 13 顿食堂猪脚饭`，或贴上 `检测到：甩锅试探` 标签），锁住用户大拇指但保留核心悬念。
  - **Layer 1 & 2（LLM 动态双回合语义攻防，`p75 ≤ 1.5s`）**：大模型负责**拆解未预写的约束组合、动态追问关键变量、扮演对手反击、并根据新事实当庭翻案**——这是静态 JSON 表 100% 无法伪造的核心智能！

#### 交锋 4：高校消防红线与虚假价格幻觉（一票否决级排雷）
- **毙掉《宿舍残局锅》**：Carbon 敏锐抓出 Neon 第一轮热门提案“宿舍电煮锅乱炖”触碰**全国高校宿舍违章电器消防高压红线**——在抖音校园联合高校官方举办的赛事路演中必遭一票否决！三方一致同意直接淘汰。
- **毙掉《凌晨两点便利店》主赛资格**：微恐台词“千万别往我身后看”易招致胆小用户负反馈与灵异机审限流，且重分支剧情掏空小团队产能，降级为番外创意。
- **修补《买前拔草审判庭》两大硬伤**：GPT 第二轮指出“LLM 编造闲鱼残值/吃灰率属虚假价格幻觉”且“随手输入法拉利 500 万计入省钱账本会毁掉数据可信度”。Carbon 提出**「JS 整数分明示基准换算 + 24h 冷静封印罐（次日复访结案入账）」**，GPT 第三轮终审将其工程可控性评分从 **3.0 分直接上调至 4.5/5 分**！

## 三、 用户、平台、程序三维深度定论与设计铁律

### 3.1 用户维度（User）：破解 Lean-back 刷屏心流的「三秒破冰公式」
1. **0–0.8 秒（骗过防广告本能）**：严禁静态海报首屏、空白输入框、多栏工具顶导。必须具备**活体微动效**（水豚戴耳机眨眼、守财猫拨算盘、来电红点呼吸闪烁）与手绘/微像素视觉异质性。
2. **0.8–2.0 秒（蔡格尼克未完成态）**：首屏直接把用户扔进**“冲突已经发生到一半”的具象切片**（如：`室友发来：“我就顺手用下你神仙水，别那么小气嘛”` 或 `购物车待结算：¥239 复古胶片机`），零规则说明，一看就懂。
3. **2.0–5.0 秒（零软键盘摩擦）**：首屏 **100% 零文本输入**，3 个高共鸣预设案卷 + 3~4 枚情绪/策略印章单指即点；把面向真实急救与评委测试的 **≤25~30 字受控自定义微表单** 放在二级抽屉入口。

### 3.2 平台维度（Platform）：双漏斗高权重指标与「无 Push 复访」四大抓手
1. **双重考核漏斗优先级**：
   - **公域算法赛马池**：`首刷首个价值结果率（2s内看到结果会话 ÷ 有效曝光）` > `首屏主动点按率` > `多轮有效状态推进（60–90s 高活跃停留）` > `右侧原生评论/收藏/分享率`。
   - **TOP150 与 Demo Day 评审席**：`现场改约束条件下的真 AI 翻案/应变能力` + `真实自然流迭代前后同口径对比证据（V1→V2 漏斗提升）` + `合规导向与长效“卡+视频”孵化潜力`。
2. **破解“兴趣卡无定时 Push 触发器”的四大原生复访引擎**（GPT 查证 AI 工坊不支持产物定时触发器）：
   - **机制复访（24h 冷静封印罐）**：首日创建悬念状态（`封印中`），驱动用户次日从**抖音个人中心/收藏夹/互动历史**主动回来点击结案。
   - **急救复访（高频场景工具箱）**：每次遇到奇葩群消息或深夜想剁手时，从收藏夹翻牌救急。
   - **评论区暗号回流**：结果页生成高辨识度《热敏纸小票 / 判决书》，引导用户点右侧评论图标晒单对暗号。
   - **连载短视频 = 最强人工 Push**：每 2 天发布一条 15 秒同系列冲突短视频并引导体验同款兴趣卡，持续召回老粉、拉动新粉。

### 3.3 程序维度（Program）：抖音 Feed 容器工程规格标准

| 模块 | 工程硬约束与推荐实践 |
| :--- | :--- |
| **视口与安全避让区** | 全卡锁死 **单屏无垂直滚动（`overflow: hidden`）**；右侧预留 `72px`（避让头像/赞/评/藏/转悬浮栏），底部预留 `110px`（避让作者名/标题/挂载条），核心点按区居中偏左下拇指热区；覆盖 iOS/Android 字号放大与展开字幕验收。 |
| **手势隔离铁律** | **零横滑、零拖拽条、零长按**；保留宿主默认上下/左右切流手势；卡内按钮监听位移阈值与 `pointercancel` 防误触；卡片交互区妥善处理连续点击，确保即便宿主偶发识别双击点赞也不中断卡片状态机。 |
| **状态机与延迟预算** | `READY → PENDING_1 → COUNTER → PENDING_2 → FINISHED`（含 `RETRYABLE / BLOCKED`）。点按本地反馈 `p95 ≤ 50ms`；端到端首个过审 AI 结果目标 **`p75 ≤ 1.5s, p95 ≤ 2.5s`**（Prompt 严控输出总长，单轮 JSON ≤ 180 tokens）；`3.0s` 客户端硬超时优雅降级为安全提示与重试钮。 |
| **幂等并发与防串台** | 每次请求携带 `(sessionId, requestId, turnNo, expectedVersion)`；服务端幂等去重，客户端丢弃切卡/重置后的过期旧响应（防止慢请求 A 覆盖快请求 B）。 |
| **双轮严格 JSON Schema** | 模型仅输出业务枚举与短纯文本（严禁输出 HTML/脚本/外部链接/未授权金额）；服务端校验字段枚举、长度上限与存在性后纯文本渲染。 |
| **云存储 `<2KB` 最小化** | 仅存结构化非敏感派生档案（偏好枚举、最近 8 条虚构场景战绩 Tag、图鉴解锁 ID、封印单状态与时间戳），序列化严格校验 **`UTF-8 < 2,000 bytes`**，绝不存储用户真实聊天隐私原文或手机号，并提供一键清空入口。 |
| **双轨输入与风控** | 首屏纯白名单枚举（0 注入风险）；二级微表单限制 `≤25~30字` + 去除手机号/微信号正则脱敏 + 前置文本安全检测 + System Prompt 权限隔离 + 输出合规过滤（禁辱骂、禁人身羞辱、禁医疗法律理财建议、保留 AI 生成合成标识）。 |

2. **首刷 3 秒零输入钩子**：
   - 屏幕上方闪烁来电气泡（内置 3 个一键切换的校园高频修罗场）：

     - *案卷 3（社团甩锅）*：「学长：今晚公众号推文临时改主题，你通宵排一下明早八点发。」
   - 中下部摆放 **4 枚高质感单指点按印章**：`🟢 先缓和` ｜ `🟡 先留证` ｜ `🟠 立边界` ｜ `🟣 玩个梗`（全档位体面合规、零脏话网暴）。

### 6.2 必埋的 5 个黄金数据埋点（GPT 制定口径）
1. `card_open`：卡片进入可交互态（区分首次访问 vs 收藏/历史复访，记录 `source`、`version`）。
2. `scenario_start`：点选首屏预设案卷或提交二级微表单（区分预设路径 vs 自定义路径）。
3. `result_outcome`：首个结果渲染状态（`success / blocked / timeout_fallback`）及端到端耗时 `latency_ms`。
4. `value_action`：核心价值达成动作（一键复制话术 / 点击收藏 / 投入 24h 封印罐）。
5. `case_resolved`：完成第二轮博弈反杀或次日完成封印罐到期结案（按记录唯一 ID 去重，直接支撑 D1 有效复访举证）。

### 6.3 最后一周最易翻车的 3 个生死大坑
1. **临交作品才第一次提审**：开放输入极易因缺少前置风控在机审阶段被打回！务必**提前一周提审 V1 纯预设版拿到上线资格**，给二级自定义微表单留好服务端独立开关（Feature Flag）。
2. **真机遮挡与手势未验**：PC 预览器好看，上真机发现底部提交按钮正好被抖音作者标题或展开字幕挡死，或小屏 iOS 溢出截断——必须在至少两台不同尺寸真机上实测。
3. **只有感想没有分母**：路演切忌只晒“总曝光 5 万”，评委只信**带分母与观察窗的转化漏斗**（如：`有效交互启动 1,240 次 → 2s内首结果达成 1,130 次 (91.1%) → 二轮深度演练 680 次 (54.8%) → 复制/封印 410 次`）。
