## 零、官方海报事实核验与赛道本质定调

### 0.1 海报核验的 5 个关键真信号（纠正常见误读）
1. **双层产品形态正式定型（核心增量）**：海报 01 栏与 05 栏两次强调——兴趣卡不仅是“信息流里可互动的 AI 内容作品，刷到即可参与互动”，而且**“还能跳转落地页深度体验”**、**“往期已跑通「兴趣卡→落地页」，可探索产品形态与商业化，让作品持续生长”**。这意味着“只做一次性纯文本卡片”的时代已过，**“卡片获客过滤 + 落地页深度交付与留存”**成为冲刺高奖与孵化的分水岭。
2. **两款官方标杆案例的真实基因**：
   - **《青松喵—轻松动一下》**：面向亚健康年轻人，点选「哪里不舒服？」→ AI 推荐适配微动作 → **10 秒短时跟练**。本质是**用低攻击性的治愈视觉异质性打破屏幕第四面墙，创造屏幕外立刻可感知的生理微收益**。
   - **《Gymimal 健身搭子》**：AI 动物搭子匹配 + 双人激励 + 每日打卡与训练计划。本质是**把冷冰冰的计划工具包装成“关系陪伴与微契约”，用连续状态撑起跨次复访**。
   - **同质化警示**：后来者如果继续扎堆做“一只手绘萌宠 + 问你累不累 + 每日打卡”，会直接撞上公域审美疲劳和评委的“静态换皮审视（Delete-AI Test）”，很难突破 TOP150 摸到万元级奖项。
3. **五层奖项矩阵对应截然不同的评判 KPI**：上线证书 → **TOP150（¥1,000 + 线下 Demo Day）** → **6 个传播奖**（破圈声量） / **15 个万元专项奖**（垂类范本） / **5 万元全场大奖**（旗舰标杆） / **官方流量与商业化孵化**（生态持续造血）。
4. **公域真实迭代要求**：模块三明确要求作品进入抖音真实信息流，基于**曝光、点击、停留**等真实数据持续迭代——这意味着**能发出去、扛住审核、拿真实漏斗做 V1→V2 迭代证据**，比纸上谈兵的宏大构想重要十倍。
5. **全球媒介坐标（2026 Playable AI Feed 浪潮）**：海外 **Meta Pocket（收购 Gizmo 演化）** 已跑通“Vibe Coding 微玩具竖屏信息流 + Remix”；**Websim** 验证了动态规则世界推演；国内 **B 站 Toy** 跑通了结果卡社交裂变，**小红书互动卡片** 跑通了审美与种草微工具。抖音的独家筹码是：**原生嵌入主站首页推荐流（无寄生视频折损）+ 7 亿全民公域 + 极强评论区辩论文化 + 电商/本地生活商业腹地**。

## 二、四大核心维度的深度定论（用户 × 平台 × 程序 × 商业化）

### 2.1 用户维度（User）：Lean-back 心流劫持与零真人依赖复访引擎

#### 1. 信息流四阈值心理动力学
- **0–1s（反射拦截期）**：用户大拇指处于 0.4–0.8s 滑屏惯性中。凡像“SaaS 表单、静态海报、>12 字规则说明、空白输入框”者，立刻触发广告防御划走。破解法：**活体微动效 + 非广告视觉异质性 + 一眼看懂的物理/冲突可供性**。
- **1–5s（姿态切换期）**：执行 **「150ms + 850ms 双拍反馈铁律」**——点击后 `0–150ms` 纯端侧确定性物理反馈（擦除、翻牌、震屏、血条变动），`150–1000ms` 吐出第一拍读心级微结果；严禁首屏打字或白色转圈。
- **5–30s（微型高潮与延迟掩蔽）**：用 **「阶梯即时回馈（Micro-Reward Ladder）」** 替代枯燥多题问卷——每次点选都立刻发放阶段性爽感，用被占据时间效应（Occupied Time Effect）无感消化后台预热/推理时间。
- **跳进落地页阈值（Portal Crossing）**：严禁写“了解更多/体验完整版”。核心驱动力是**“带走刚打出的沉没资产 / 延续未完契约”**。通过 **三字段最小状态包（`seed_context` 已选约束 + `earned_artifact` 沉没战果 + `unfinished_hook` 悬空下一幕）** 让落地页首屏 0.5 秒“认出你”，直接从第 2 幕开演。

#### 2. 经平台排雷的 3 套「无真人实时依赖」跨赛道复访元机制
解决“病毒玩具次日留存归零”与“双人搭子冷启动空房跑路”的通用解：

| 元机制 | 生态评分 | 核心玩法逻辑 | 平台红线与排雷改造（Carbon & GPT 审计） |
| :--- | :--- | :--- | :--- |

### 2.2 平台与生态维度（Platform）：战略意图、算法赛马与多元奖项博弈

#### 1. 抖音为什么此刻押注「兴趣卡 → 落地页」？（4 大高层焦虑）
1. **破解 AI“对话框失语症”与买量死局**：90% 普通用户面对空白输入框不知写啥 Prompt，独立 AI App 获客成本高企；兴趣卡把 AI 封装成零输入 GUI 微组件，直接塞进公域推荐流实现**“算法主动喂场景”**。
2. **对抗短视频时长见顶与跨平台截流**：防御微信小游戏（即点即玩 + IAA/IAP）、小红书（种草决策工具）及海外 Meta Pocket（Vibe Coding 竖屏玩具流），把用户单次消费从 8 秒被动观看拉升至 45–120 秒主动把玩。
3. **补齐“零方结构化意图数据（Zero-Party Data）”中间层**：用户在卡内点选的肤质/预算/痛点/场景，先靠 10 秒微价值完成需求自证，再顺滑导入落地页转化，大幅降低传统挂链 70%+ 的跳失率。
4. **高校 WowLand 作为低成本 PMF 试验田**：用轻奖金池发动零包袱、强网感的大学生特种兵，批量跑出原生交互范本与商业化雏形。

#### 2. 信息流算法 7 阶赛马指标与合规全域飞轮
- **7 阶漏斗**：`L1 3秒首屏阻停` → `L2 首触交互率（一级生死线）` → `L3 多步完成率` → `L4 带交互心跳的有效停留（35–90s）` → `L5 评论站队/收藏/自然转发（大流量池核燃料）` → `L6 落地页高意愿自然二跳` → `L7 复访与二创回流`。
- **合规全域四触点飞轮**（已剔除诱导互动红线）：
  1. **短视频喂流校准标签**：用 15 秒实测反应/情景反差短视频帮新卡精准对齐初始人群包（挂载走大赛官方通道、KOC 代挂或先破 500 有效粉）；

### 2.4 程序与工程维度（Program）：容器边界、L1/L2 架构、风控与科学归因

#### 1. 信息流卡片容器 vs 落地页能力边界与 3 级状态续接
“落地页”实际可能是工坊托管页、获准 H5 或抖音小程序，三者布局、身份、网络白名单与导航参数须在 Day 1 实测确认：
- **卡片层设计起点**：锁死单屏可用矩形（预留右侧互动栏与底部文案/系统安全区，覆大字号与字幕展开态）；主动作只依赖 Pure Tap；资源就绪到可操作目标 **p95 ≤ 800ms**，点击到可见反馈 **p95 ≤ 100–150ms**；滑走即停动画、音频与轮询。
- **3 级跨页状态续接方案（按真机实测结果降级选型）**：
  1. **动态参数 + 服务端存储可用**：写入成功后签发短期、限用途随机 `handoff_id`，落地页校验作品、版本、有效期与主体后恢复状态；
  2. **仅支持静态参数/枚举**：用 `/go/cardA_opt2` 或 `preset=desk_break` 路由直达对应预设分支，同时兼作分段到达率归因编码；
  3. **无传参/无跨端身份**：落地页从通用态启动并提供一次轻量补选，两端各自独立统计漏斗并如实标注跨端关联覆盖率。

#### 2. 五类 AI 架构范式选型与「Day 1 必做 vs PMF 后升级」工程分界（YAGNI 原则）
- **五类范式**：① 规则 + 结构化 LLM 状态机（TTFT ≤ 0.8s，可用结果 ≤ 2s，3s 切兜底）；② 多模态视觉/生图异步流水线（建单 ≤ 500ms，生图预览 ≤ 8s，避免 60–120s 同步视频）；③ 端侧 Canvas/轻量交互 + 云端回合结算（不按帧调模型，60Hz 按 16.7ms 预算）；④ 异步共享状态/分章投票（事务去重 + 分桶计数 + 定时发布快照）；⑤ 跨日云存储与个人档案（账号隔离 + 版本校验 + 撤权防旧任务回写）。
- **爆量三态熔断算例**：假设 60s 涌入 3 万访问、10% 发起 L2（50 任务/秒），上游 600 RPM / 90 万 TPM / 24 并发（每单 3s）→ 实际瓶颈 8 单/秒 → 留 25% 余量设准入上限 **6 单/秒**、5 秒排队即队列上限 **30 单**。分三态处置：**正常**（幂等防双击建双单）→ **拥塞**（先停生图与扩写、队满返可继续的轻量玩法）→ **熔断**（切离线预审样板，冷却后小流量探测恢复，审核故障期间待审成品保持私有）。

#### 3. 开放上传/自由输入到可分享成品图的「5 道独立阻断安全流水线」
1. **入口隔离与洗净**：明示用途、留存期与删除方式；服务端限格式/大小/像素并重编码，清除 EXIF/定位，禁用用户自填外链图 URL，原图进私有短期隔离区。
2. **并行审图 + OCR + 脱敏**：并行跑图像内容安全与 OCR，检出人脸、证件、门牌、二维码或可定位地标即要求重裁或切样板；聊天截图缺对方授权且无法充分脱敏则拒收。
3. **最小权限隔离模型**：把正文/OCR 视为不可信数据；模型无联网、写库、发布与跨会话读权限；输出锁死严格 JSON Schema 白名单枚举与字长上限。
4. **服务端固定模板渲染 + 成品复审**：渲染器仅接收校验字段纯文本绘制并截断溢出；合成成品图**再过一次图审与 OCR**，防止隐私回填、违禁词或仿官方公章。
5. **合规标识随文件交付**：按 2025/2026 现行规范，同时落实图面显式标识 + **GB 45438-2025 隐式文件元数据**（生成合成属性、服务提供者编码、内容编号）与平台发布声明，对最终下载文件回读校验。

#### 4. Vibe Coding 双轨工作流（避开最大返工源）
- **最大坑点 = 跨模块隐式修改**：不要对 AI 喊“顺手整体优化一下”（会同时改乱布局、状态机、Prompt 与埋点导致无法归因）。
- **零基础创作者**：先写状态表（`初始 → 已选 → 结果 + 超时/取消/切换`），选项/文案全放独立配置表，每次 Prompt 只改一个模块并附带 1 条可复现验收标准（如“快速连点 A 再点 B，最终只能展示 B”）。
- **硬核技术团队**：严格拆分平台适配层、状态机、模型推理、审核与埋点模块，用本地替身测试乱序响应、429、超时、重复提交与撤权写回竞争，再上真机审核版验收。

### 3.2 终局盲区扫描补齐的「6 大破界开放方向」（真正不局限！）

3. **从“做单张卡”升维为“造卡母版平台”（B2B2C 生产力破界）**：不再只做一张给 C 端玩的卡，而是做**让万千垂类博主 3 分钟填入自己测评表/考公题库/穿搭公式就能一键生成专属互动卡的母版容器**（靠 `creator_id` 动态加载配置）——搞定 1 个腰部达人主动挂载 = 零买量撬动 10 万精准 UV！

#### 程序与技术格局破界（GPT 终局补全）
4. **声明式可配置母版（一核多端架构）**：把交互状态机、内容约束和事件埋点抽成同一份声明式配置，用两套不同题材验证复用能力，通过薄适配层同时输出**抖音兴趣卡 + 独立 Web + 小程序**，让代码资产赛后也能独立生长。

### 4.2 不可妥协的 5 条交付底线 vs 创作者自由探索区
- **5 条铁打底线（GPT × Carbon × Neon 三方联署）**：
  1. **卡内必有完整结果**：静音、断生成或落地页不可用时，卡片核心玩法依然完整可结束；
  2. **能力逐项真机验收**：绝不把编辑器预览当成审核版推荐流表现，缺失权限按已验证路径收敛；
  3. **算力与状态有硬上限**：并发、日预算、超时、重复提交与过期链接全有确定性兜底行为；
  4. **私有输入与公开成品独立防护**：未脱敏/无授权素材必拦，模型最小权限，成品复审 + GB 45438-2025 显隐式标识齐全才可导出；
  5. **数据与商业证据口径诚实严谨**：不把观察性汇总吹成因果增量，不把自报付费意愿包装成真实交易，个人 Demo 用免费体验漏斗 + 合规实证说话。
- **完全开放、绝不设限的创作者自由区**：题材视野（全民/垂直/公益/B端/亚文化均可）、角色与视觉美术语言、微动效与节奏演出、声音表演、虚构世界规则、以及赛后向母版引擎/独立产品演进的想象力。

### 4.3 Demo Day 评委最吃香的「三份现场可核对证据」
1. **真实链路证据**：在真实抖音入口（注明正式流/官方入口）真机跑一遍完整闭环——卡内单击出结果 → 跳落地页无损恢复同一选择 → 同步出示服务端可关联的事件日志与版本号。
2. **真实失败与抗造证据**：现场切弱网/触发超时展示丝滑降级，双击按钮证明只建一单、只扣一次费，换账号打开私有链接验证拒绝越权。
3. **真 AI 增量 + 商业/生态实证**：现场请评委对一个未见真实案例**临时新增一条苛刻约束**，并排盲评对比“尽力实现的规则模板版”vs“你的实时 AI 版”（展示约束满足率、耗时、成本），再甩出 eCPM 毛利账本、B 端小店实测对比或二创 K 值。
