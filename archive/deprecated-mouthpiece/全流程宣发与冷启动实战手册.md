## 一、0 粉冷启动怎么把卡片推给真实用户？

1. **优先走赛事官方兴趣卡挂载通道**：参赛报名后第一时间在官方群确认本次活动的兴趣卡提审与 Feed 直投/官方代挂通道，避免被个人号 500 粉自主挂载门槛卡死。
2. **个人账号同步做“零出镜 3 条连载录屏”起号**：
   - 不需要露脸、不需要买灯光、不需要写段子，用下方 **3 分钟出片流水线** 直接录制 Demo 手机模拟器画面；
   - 第一周密集发 3 个不同冲突题材（`周六老板催改` / `小组白嫖署名` / `过年二姨催婚`），谁先突破 2,000 播放就全力做同题材 V2 变体。

## 二、3 分钟零出镜出片流水线（直接用 Demo 录屏）

1. 双击打开 [demo/index.html](file:///E:/Project/抖音大赛/demo/index.html)（电脑屏幕开启局部区域录屏，框住左侧 `390×844` 手机画面）。
2. 在左侧或右上角选择目标场景，点击顶部红色按钮 **`🎬 一键演播12秒宣发视频`**。
3. Demo 会自动以标准抖音频奏跑完：**0–3s 高冲突弹窗钩子 → 点左下角进卡 → 按【🔴 体面发疯版】→ 对方撤回消息+内心 OS 暴击 → 红印盖章吐小票 → 落地页一句话定制对比**。

## 三、3 套合规爆款脚本与评论区自发升温红线

- **核心抓手（合规）**：在发布后的首条置顶评论里，抛一个**有明显站队分歧的非诱导提问**（如 *“周六 22:47 老板发在吗，你敢发红牌还是乖乖保命？”* 或 *“精神支柱兼锦鲤顾问笑不活了，遇到白嫖队友你会私聊还是群里说？”*），引发路人自发争辩与 `@好友`。
- **绝对红线（严禁触碰）**：严禁写任何 *“评论区扣 1 解锁隐藏话术 / 转发好友才能看结果 / 点赞过千放源码”*，直接触发平台诱导互动限流或下架。

## 四、发布后 48 小时 V1 → V2 漏斗诊断（一次只改 1 项）

| 你看到的异常现象 | 最常见真病因 | 48 小时 V1→V2 单变量改法（Demo 作战台可查） |
| :--- | :--- | :--- |
| **播放卡在 200–500** | 视频前 3 秒像功能说明书，路人 0.8s 划走 | 砍掉介绍，第一帧直接大红字+震动放“周六 22:47 老板发在吗” |
| **进卡后首触率 < 10%** | 文字太长像问卷，或按钮掉入右侧/底部安全遮罩区 | 开启 Demo `安全区参考线`，首屏消息压到 22 字内，放大三枚火力技能卡 |
| **点完 1 轮就划走** | 第一轮太温和，缺乏对方反扑悬念 | 强化第 1 轮 `opponentCounter` 嘴硬程度 + `撤回一条消息` 提示 |
| **小票好看不进落地页** | 跳转文案写“查看更多”缺乏动因 | 改为“按我的真实对话改写”，并在落地页首屏直接展示带入的段位战绩 |
