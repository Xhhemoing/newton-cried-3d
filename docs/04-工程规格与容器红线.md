# 抖音兴趣卡（Lynx OpenCard + Taro 落地页 + NestJS）工程红线速查表

> **说明**：本文档基于官方 [`interest_card_skills/`](../interest_card_skills/README.md) 与本项目「零长文阅读、全程零软键盘、纯点按反馈」铁律提炼，供编码与静态检查直接对照。

---

## 一、 `card-app/opencard/src/`（信息流兴趣卡 · Lynx 引擎）硬约束

1. **尺寸与布局**：
   - 核心内容必须在 **`300` 和 `436` 两档槽高** 下完整显示、水平居中、无重叠、无裁边；
   - 保留平台模板 `.widget-root`（半透明圆角底板、非透明、1px 边框、四角 `12px`）与 `.widget-body`（唯一 Actual FMP 标记挂在 Body，禁止在业务分支新增 FMP 标记）；
   - **卡内禁止重复宿主已展示的业务标题**，默认不重复宿主外壳同语义落地页按钮（确需特定状态跳转时，目标路径必须真实存在于 `src/app.config.ts` 且不带前导 `/`）。
2. **CSS 与组件禁区**：
   - **严禁 `@media` 媒体查询**；
   - **严禁纵向滚动**（`overflow-y: scroll/auto` 或 `<ScrollView scrollY>` 兜底），放不下先减项或延后到落地页；
   - **不安装、不使用 `@open-dy/lucide-taro` 图标包**（该包仅限落地页 `src/` 使用）；
   - **严禁在卡代码内自实现背景音乐播放**（`BgMusicUrl` 只配在 `feed/feed-card.json` 由宿主统一播放与切流管控）。
3. **手势与交互禁区**：
   - **严禁 `<Input>`、`<Textarea>`、`<Slider>`、拖拽及任何时长的长按交互**；全部采用纯点按（`onClick` / `onTap`）即时状态反馈。
   - **严禁编写浏览器 DOM / H5 兼容分支**（禁止 `document.*`、`window.localStorage`、`Taro.getEnv() === Taro.ENV_TYPE.WEB`）。

---

## 二、 `card-app/src/`（落地页）与 `card-app/server/`（开放域服务）硬约束

1. **落地页（`src/`）**：
   - 常规 Taro + React 小程序页面，严守本项目**全程零软键盘铁律**（禁止文本输入框，用图标/标签点选驱动交互与 AI）；
   - 涉及持续 Canvas 2D / 动画帧循环时，必须实现页面隐藏（`useDidHide` / 后台态）立即 `pause` 停帧静音、显示（`useDidShow`）幂等 `resume` 恢复；
   - 图标统一从 `@open-dy/lucide-taro` 导入（禁止导入 `lucide-react`）。
2. **服务端（`server/`）**：
   - 动态业务数据统一走服务端接口；卡片首屏与状态接口按规范实现 `/api/dy_card/data` 与 `resolveCardData()`；
   - 生产运行所需第三方包必须写入 `server/package.json` 的 `dependencies`（严禁只放 `devDependencies` 或仓库根目录，否则线上 Docker `npm install --production` 会报 `MODULE_NOT_FOUND`）；
   - 严禁硬编码密钥、数据库凭据、完整域名或 `localhost`；严禁 SQL 字符串拼接或 `exec/execSync` 命令注入；
   - 依赖平台环境的抖音用户身份、OpenAPI（`@open-dy/ai_coding_sdk/openapi`）与平台大模型（`ai-platform-llm-skill`），本地先用结构化 Mock 兜底并用清晰注释标明接入点，**严禁臆造未公开 SDK 接口**。

---

## 三、 外框配置与交接打包（`handoff.zip`）硬约束

1. **`feed/feed-card.json` 铁律**：
   - `ContentInfoList[].PageIndex` 与 `PageURL` **严禁以 `/` 开头**（正确示例：`pages/index/index`）；
   - 本地大图片与音频严禁内联打入包体（`dist-tt` 与 `opencard/dist` 均须 `<= 16 MB`），交接回平台后由平台 AI 调用 `transfer_file` 转存 CDN URL、调用 `mm_tool_music_*` 或曲库配置 `BgMusicUrl`。
2. **`handoff.zip` 交接包红线**：
   - **只允许包含**：`card-app/` 对应层级的业务代码（`opencard/src/**`、`src/**`、`server/src/**`）、`DESIGN.md`、用到的本地素材文件，以及说明合并位置的根目录 `README.md`；
   - **严禁包含**：`package.json`、`pnpm-lock.yaml`、`node_modules/`、`dist/`、`dist-tt/`、`.env*`、密钥文件以及平台模板自带的基础工程配置文件。
